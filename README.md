# Mission Shakti Maharashtra — Frontend Redesign

A responsive, frontend-only redesign concept for a Maharashtra Women & Child Development Department / Mission Shakti information portal.

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use **Live Server** if installed, or open `index.html` directly in Chrome.
4. Every major navigation item/card is configured to open its relevant page in a new tab.
5. No backend or database is included.

## Main pages
- Home
- About Us
- Mission Shakti
- Citizen Charter
- Downloads
- Right to Information (RTI)
- Right to Service (RTS)
- 100 Day Program Report
- Contact Us

## Notes
- The visual content uses remote Unsplash images, so internet access is needed for the photos.
- Official document links point to the Maharashtra Women & Child Development Department or official government portals.
- Login, screen-reader control and some accessibility controls are frontend demonstration interactions and should be connected to real services before production deployment.
